# 기능 구현 문서

# 감성 분석 기능

## 입력 처리

사용자가 텍스트 입력 후 버튼 클릭.

---

# API 요청

POST /analyze

## 요청 예시

```json
{
  "text": "오늘은 정말 행복한 하루야"
}
```

---

# 응답 예시

```json
{
  "sentiment": "긍정",
  "confidence": 95,
  "reason": "긍정적인 감정 표현 포함"
}
```

---

# 로딩 처리

분석 중:
- 버튼 비활성화
- 로딩 메시지 출력

---

# 오류 처리
